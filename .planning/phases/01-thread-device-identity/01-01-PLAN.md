<objective>
Capture the pre-change wire baseline, then wire a Thread device end to end: a `Connectivity`
value on a frozen `NetworkState`, a `thread_connection` bit on `LifxHeader`, and one stamping
point in `EmulatedLifxDevice.__init__` so every reply a Thread device emits carries frame-address
byte 22 bit 3 while a WiFi device's bytes do not move.

Purpose: prove the whole vertical path — public enum, factory argument, builder, device state,
response header template, wire bytes — before any of the derived rules (firmware, `wifi_signal`,
per-tile mirror, persistence) are layered on. If bit 3 cannot reach every reply shape through the
single template, that is an architectural dead end and it surfaces after one commit rather than
after four plans.

Output: two new test modules holding the committed byte baseline plus the end-to-end assertions,
`Connectivity` exported from `lifx_emulator`, and `create_device(pid, connectivity="thread")`
producing a device that sets bit 3 on data replies, acknowledgements and `StateUnhandled`.
</objective>
