<objective>
Let the standalone app create Thread devices from CLI flags and YAML, turn mDNS on automatically
only when a Thread device is configured, and refuse to start when mDNS is explicitly disabled for a
fleet that contains Thread devices (CFG-01 Thread and mDNS flags, CFG-02 Thread and per-device keys,
CFG-04, CFG-06 app rule; SPEC R2 mDNS half, R3, R4, R5; D-11, D-12, D-13).

Purpose: A Thread device is only discoverable through mDNS, but mDNS records can leak onto a real
LAN on Linux (AR-06), so enablement must follow the fleet: automatic for Thread, opt-in otherwise.

Output: `--thread`, `--thread-product`, `--mdns`/`--no-mdns`; the matching YAML keys and
validators; Thread count-device creation; the first preflight step; and tests including the P1, P3
and P4 prohibitions.
</objective>
