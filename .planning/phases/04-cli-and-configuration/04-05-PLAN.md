<objective>
Let the standalone app choose the IPv6 bind address and the server-level advertised mDNS address per
family from CLI flags and YAML, validate them with errors that name the flag or key the value came
from, and check wildcard binds in the preflight (CFG-01 address flags, CFG-02 address keys; SPEC R2
address half, R6; D-01 app side, D-03, D-11, D-12).

Purpose: Thread devices are reachable only over IPv6, and a wildcard bind cannot be advertised, so
a user who binds `::` or `0.0.0.0` must be able to name the address clients should use, and must be
told before anything binds when they have not.

Output: `--ipv6-bind`, `--mdns-ipv4-address`, `--mdns-ipv6-address`; the matching YAML keys and
shared validators; the wildcard and ignored-address preflight checks; `test_cli_addresses.py`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI flags and YAML file to bind and advertised addresses | Untrusted strings choose which interface binds and what address the LAN is told to use |
| App to the LAN via mDNS | Advertised A/AAAA records direct clients to an address |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-18 | Tampering | config.py validators and RunSettings.validation_problems | medium | mitigate | validate_ipv6_bind plus the core validate_mdns_address reject empty, wrong-family, scoped, link-local, unspecified, multicast and broadcast values before any socket, naming the flag or key |
| T-04-19 | Information Disclosure | preflight advertised-address check | medium | mitigate | The same core resolve_address rule the server uses runs before binding, so a wildcard bind can never be advertised and every affected device is reported |
| T-04-20 | Repudiation | ignored-address warning | low | mitigate | One WARNING names every ignored address option when mDNS is off (D-03), so a user is never silently ignored |
| T-04-21 | Information Disclosure | --bind 0.0.0.0 / --ipv6-bind :: | low | accept | Binding every interface is an explicit user choice already available through --bind; the loopback defaults are unchanged |
</threat_model>
