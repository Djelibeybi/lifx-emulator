## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UDP datagram → protocol/parser | Untrusted network bytes and peer metadata enter parsing, statistics and scheduling. |
| Parsed target → device manager | Untrusted header targeting is evaluated against emulator device identity and connectivity. |
| Protocol context → response transport | A request-selected endpoint controls the address family and socket used for replies. |
