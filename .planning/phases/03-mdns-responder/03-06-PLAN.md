## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| synchronous membership callback → async zeroconf work | Committed device changes admit background registration work. |
| zeroconf supported-operation exception → server lifecycle | Third-party async errors can retain LIFX service or trigger full shutdown. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-06-01 | Denial of Service | lifecycle lock and failure handler | high | mitigate | Surface errors after responder locks release, schedule one handler, acquire server lock once and call locked helpers directly; add a deadlock regression test. |
| T-03-06-02 | Tampering | overlapping membership generations | high | mitigate | Serialise immutable snapshot reconciliation, use monotonic generation/tail barriers and assert no stale re-add/partial publication. |
| T-03-06-03 | Denial of Service | retained tasks/sockets/listeners | high | mitigate | Stop admission, remove listener, boundedly drain/cancel work, unregister and close idempotently across partial/repeated lifecycle paths. |
| T-03-06-04 | Repudiation | mDNS status/error | medium | mitigate | Retain the surfaced exception and log state transitions; define running as lifecycle state so unsupported health is never misreported. |
| T-03-06-05 | Information Disclosure | automatic recovery/interface change | low | accept | No automatic retry or interface selection occurs; explicit retry reuses validated configured addresses only. |
</threat_model>
