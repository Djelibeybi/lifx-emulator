<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public factory caller → immutable device state | Caller-controlled enablement and address text becomes advertisement policy. |
| bind configuration → LAN-visible address records | Server bind intent supplies fallback addresses only when concrete and family-correct. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04-01 | Information Disclosure | advertised address fallback | high | mitigate | Reject wildcard and link-local fallback/overrides, require explicit addresses for wildcard binds and prohibit automatic interface enumeration. |
| T-03-04-02 | Tampering | factory address/family inputs | medium | mitigate | Parse and validate once before state construction, store canonical immutable intent and revalidate bind-dependent rules before membership. |
| T-03-04-03 | Spoofing | shared-address service identity | medium | mitigate | Key service instances by immutable 12-hex serial rather than address and test two serials sharing one address. |
| T-03-04-04 | Denial of Service | invalid live additions | low | mitigate | Reject before repository mutation, callbacks, persistence activation or zeroconf work allocation. |
</threat_model>
